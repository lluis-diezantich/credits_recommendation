# DN: Short title, stating the decision rather than the topic

- **Status:** Accepted | Proposed | Superseded by DM (link the newer file)
- **Date:** YYYY-MM-DD (last status change)
- **Where it lives:** the files that implement it, so a reader can check the
  decision against the code rather than trusting this file

## Context

What forces the decision. Facts and constraints, not intentions.

## Options

1. **Option A:** what it buys, what it costs.
2. **Option B:** ditto.

Only the options actually weighed. One option means say so.

## Decision

The chosen option, in a sentence or two.

## Evidence

The measurement the decision rests on, with its date and the artists or files
it was taken over. A decision with no number here says so in one line -- "not
measured, chosen for X" -- because this repo's rule is that a threshold arrives
with evidence or not at all, and an ADR that quietly skips this looks measured
when it is not.

## Consequences

What this makes easy, what it makes hard, and what it rules out. The follow-ups
it leaves, by their entry in [../../todo.md](../../todo.md). What would reopen it.
